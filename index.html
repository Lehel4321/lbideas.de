I write the control software for special-purpose machines on Siemens S7. Mostly in SCL, often with servo motion and safety.

Ich schreibe die Steuerungssoftware für Sondermaschinen auf Siemens S7. Meistens in SCL, oft mit Servoachsen und Sicherheitstechnik.

Ich programmiere SPS seit 2014, zuerst in Rumänien und seit 2019 in Deutschland: Kläranlagen, Mehlsilos, Dosieranlagen für Schotterwerke und seit 2022 Schneide- und Umformmaschinen bei der Metzner Maschinenbau GmbH in Neu-Ulm. Ich begleite eine Maschine vom ersten Gespräch mit dem Kunden bis zur Inbetriebnahme vor Ort.

Machines I worked onMaschinen, an denen ich gearbeitet habe

  • Dynamite cutting machine. High-speed cutting of explosives with servo motion and an F-CPU.

  • Better cam profiles. S-curves instead of trapezoid ramps, so the motion is smoother and motors and mechanics wear less.
  • Calculation tools for sales and design. Machine limits like line speed and parts per minute on the spot, so sales can answer a customer straight away.
  • Fertigungsanlage für Aluminiumteile. Zuführband, Exzentermesser mit Kurvenscheibe und Locher. Jedes Teil wird auf Länge und Lochposition geprüft, Ausschuss wird über ein schnelles Ventil ausgeblasen. Durch die Synchronisierung von Band und Messer stieg die Stückzahl pro Minute.
  • Dynamit-Schneidemaschine. Schnelles Schneiden von Sprengstoff mit Servoachsen und F-CPU.
  • Rohr-, Kabel- und Gummiverarbeitung. Servogesteuertes Schneiden, Abisolieren und Umformen. An einer Gummischneidemaschine ging es zusammen mit der Konstruktion von 57 auf 63 m/min, also etwa 10 % mehr.
  • Bessere Kurvenscheiben. S-Kurven statt Trapezrampen, damit die Bewegung ruhiger läuft und Motoren und Mechanik weniger verschleißen.
  • Berechnungstools für Vertrieb und Konstruktion. Maschinengrenzen wie Liniengeschwindigkeit und Stück pro Minute sofort, damit der Vertrieb dem Kunden direkt antworten kann.

Side projectEigenes Projekt

Machine control on an S7-1500T with a .NET operator panelMaschinensteuerung auf einer S7-1500T mit .NET-Bedienpanel

A complete machine project of my own, from the PLC program to the operator panel. Motion and safety run in an S7-1500T(F). The operator panel is a .NET 8 application that talks to the CPU over the S7-1500 Web API, with Siemens' own client library.

Ein komplettes eigenes Maschinenprojekt, vom SPS-Programm bis zum Bedienpanel. Bewegung und Sicherheit laufen in einer S7-1500T(F). Das Bedienpanel ist eine .NET-8-Anwendung, die über die S7-1500 Web API mit der CPU spricht, mit der Client-Bibliothek von Siemens.

In the PLC (SCL, TIA Portal V21)In der SPS (SCL, TIA Portal V21)

  • Technology objects with electronic cam (MC_CamIn), homing, phasing, and a controlled stop that always finishes the running cycle.
  • F-program for E-stop, guard locking, SS1 and STO. The panel only reads the safety state and can never acknowledge anything.
  • Watchdog on the panel's heartbeat, and a command handshake with sequence number and acknowledge.
  • OPC UA interface for the customer's MES: machine status, active recipe, recipe load from outside.
  • No global data inside any FB or FC, everything goes through the block interface.
  • The whole program imports and compiles in TIA Portal V21 with 0 errors on a CPU 1511T-1 PN.
  • Technologieobjekte mit elektronischer Kurvenscheibe (MC_CamIn), Referenzieren, Phasing und ein kontrollierter Stopp, der den laufenden Zyklus immer zu Ende fährt.
  • F-Programm für Not-Halt, Zuhaltung, SS1 und STO. Das Panel liest den Sicherheitszustand nur und kann nichts quittieren.
  • Watchdog auf den Heartbeat des Panels und ein Befehls-Handshake mit Sequenznummer und Quittung.
  • OPC-UA-Schnittstelle für das MES des Kunden: Maschinenstatus, aktive Rezeptur, Rezeptur von außen laden.
  • Keine globalen Daten in FBs und FCs, alles läuft über die Bausteinschnittstelle.
  • Das gesamte Programm lässt sich in TIA Portal V21 auf einer CPU 1511T-1 PN importieren und übersetzt mit 0 Fehlern.

In the operator panel (.NET 8, Blazor)Im Bedienpanel (.NET 8, Blazor)

  • Cam profiles calculated in the panel from the recipe and downloaded to the PLC as a point table.
  • Operator screen with an animated machine view, recipes, production counters and an alarm history with the Siemens alarm texts.
  • A trend screen modelled on TIA Trace: the last 30 minutes of every signal, cursors, zoom, CSV export.
  • Users and rights like on a Siemens HMI, German and English texts, and an audit log of every changed value.
  • "Ask the machine", a prototype assistant: an operator asks "why did it stop?", it reads alarms, production data and trends and answers. It can only propose a change, a person has to confirm it.
  • Runs on a panel PC as a Windows service with a kiosk browser, log files and a daily backup.
  • End-to-end tests through the Siemens client against a simulated PLC: accuracy within ±0.05 mm, E-stop, overspeed, watchdog.
  • Kurvenscheiben werden im Panel aus der Rezeptur berechnet und als Stützpunkttabelle in die SPS geladen.
  • Bedienbild mit animierter Maschinenansicht, Rezepturen, Produktionszählern und Alarmhistorie mit den Siemens-Meldetexten.
  • Ein Trendbild nach dem Vorbild von TIA Trace: die letzten 30 Minuten jedes Signals, Cursor, Zoom, CSV-Export.
  • Benutzer und Rechte wie auf einem Siemens-HMI, deutsche und englische Texte und ein Änderungsprotokoll für jeden geänderten Wert.
  • „Frag die Maschine“, ein Assistent als Prototyp: Der Bediener fragt „Warum hat sie angehalten?“, der Assistent liest Alarme, Produktionsdaten und Trends und antwortet. Er kann Änderungen nur vorschlagen, bestätigen muss ein Mensch.
  • Läuft auf einem Panel-PC als Windows-Dienst mit Kiosk-Browser, Logdateien und täglicher Sicherung.
  • End-to-End-Tests über den Siemens-Client gegen eine simulierte SPS: Genauigkeit innerhalb ±0,05 mm, Not-Halt, Überdrehzahl, Watchdog.

How I workArbeitsweise

I keep a written rule book for my SCL, based on the Siemens Programming Guideline and Styleguide. No global data inside FBs and FCs, everything passes through the block interface. One condition per line in IF statements. Every block starts with a header and a change log. A small script checks each block against these rules before it goes into TIA Portal.

Für mein SCL habe ich ein schriftliches Regelwerk, angelehnt an den Siemens Programmierleitfaden und Styleguide. Keine globalen Daten in FBs und FCs, alles läuft über die Bausteinschnittstelle. Eine Bedingung pro Zeile in IF-Anweisungen. Jeder Baustein beginnt mit Kopf und Änderungshistorie. Ein kleines Skript prüft jeden Baustein gegen diese Regeln, bevor er ins TIA Portal geht.

For the import I wrote a tool on TIA Openness. It creates the CPU and the technology objects, imports the blocks and tags, compiles and reads the errors back. A complete desk project builds from an empty TIA project in about two minutes. LAD and FBD blocks come out as SimaticML XML that TIA imports directly.

Für den Import habe ich ein Tool auf Basis von TIA Openness geschrieben. Es legt CPU und Technologieobjekte an, importiert Bausteine und Variablen, übersetzt und liest die Fehler zurück. Ein komplettes Tischprojekt entsteht so aus einem leeren TIA-Projekt in etwa zwei Minuten. KOP- und FUP-Bausteine kommen als SimaticML-XML heraus, das TIA direkt importiert.

Everything I learn along the way goes into a private knowledge base: Siemens motion control, OPC UA setup, cam design, drive sizing, commissioning notes. That way the next machine starts from what the last one taught me.

Was ich dabei lerne, landet in einer privaten Wissensdatenbank: Siemens Motion Control, OPC-UA-Einrichtung, Kurvenscheiben, Antriebsauslegung, Notizen aus der Inbetriebnahme. So startet die nächste Maschine mit dem, was die letzte mir beigebracht hat.
